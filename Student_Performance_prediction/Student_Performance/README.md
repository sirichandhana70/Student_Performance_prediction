# CA1 — Student Performance Prediction using Advanced Regression

**Dataset source:** CSV and baseline project provided by the student from the GitHub Student-Performance-Prediction-using-Linear-Regression repository. This is an expanded educational implementation, not the original repository code.

## Quick start
1. Install Python 3.10+.
2. In this folder: `pip install -r requirements.txt`
3. Run `python project.py` OR open `CA1_Student_Performance.ipynb` in Jupyter and Run All.
4. View `results/` for comparison CSV, plots, tuning parameters and best model.

**Important:** Model selection uses 5-fold CV on training data only. The 20% test split is used for final reporting. For a strict unbiased estimate after extensive tuning, use nested CV or a final untouched external test set.

**Files:** project.py, CA1_Student_Performance.ipynb, Student_Performance.csv, requirements.txt, results/, REPORT.md, VIVA.md.
